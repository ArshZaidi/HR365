# HR365 — Main Features (DUMMY DATA)

> **DUMMY DATA WARNING**: This is fictional seed content for demonstration
> purposes only. Do not cite it as fact.

## 1. Employee Information Management

- Central employee directory with profile records.
- Fields include employee ID, department, role, manager, joining date, and
  contact information.
- Role-based access: employees can view their own records; HR admins can
  edit all records.

## 2. Leave Management

- Employees can request annual leave, sick leave, and unpaid leave.
- Managers approve or reject requests from a dashboard.
- A leave balance is maintained per employee per leave type.

## 3. Attendance Tracking

- Daily check-in and check-out.
- Automatic calculation of working hours.
- Flags for late arrivals and missed check-outs.

## 4. Analytics Dashboard

- Headcount by department.
- Leave utilisation trends over time.
- Attendance summaries for managers.

## 5. AI-Assisted HR Queries

- Natural-language question answering over HR documents.
- Answers are grounded in retrieved passages; sources are always returned.
- If the documents do not contain the answer, the assistant says so instead
  of guessing.

## 6. Document-Based Answering

- HR policies, FAQs, and onboarding guides can be dropped into the raw data
  folder and indexed automatically.
- Supports `.md`, `.txt`, and `.pdf` files.
